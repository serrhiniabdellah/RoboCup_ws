🚀 DÉMARRAGE EXPRESS (si vous êtes pressé) :

   1. Vérifier Docker :
      $ docker ps

   2. Si erreur de permission :
      $ sudo usermod -aG docker $USER
      (puis se déconnecter/reconnecter)

   3. Lancer le robot :
      $ cd ~/RoboCup_ws
      $ ./launch_robot.sh
